# AG Man v0.2.0 發版說明 (Release Notes)

發布日期：2026-11-21  
前一版本：v0.1.0 (2026-10-23)  
變更總覽：約 1,029 個 commit（包含 302 項新功能、511 項修正、66 項測試、35 項重構、30 項文件與 26 項效能改進）

## English Summary

AG Man v0.2.0 is a major milestone introducing direct **API bots** (`claude-api` and `openai-api`), significant enhancements to multi-agent fleet operations in **Expert Mode**, redesigned **Identities and Host Management**, global **API Balance Visibility**, and smarter **Web Push Notifications**.

### Key Highlights
- **Direct API Bots (`claude-api` & `openai-api`)**: Connect directly to Anthropic and OpenAI APIs without needing CLIs or terminal panes. Designed specifically as dedicated project **advisors**, supporting per-turn cost ceilings (or unlimited) with detailed token/cost breakdown.
- **Enhanced Expert Mode & Cluster Dispatch**: Full support for Manager, Executor, Advisor, Scheduler, and Specialist roles. Executors with matching configurations automatically form clusters. Individual or cluster-wide `manager_use` toggles prevent unwanted quota usage.
- **Redesigned Identities Page & ag0 Support**: Browse credentials across hosts with host tabs and dedicated CLI cards (Claude, Codex, Grok, agy). agy default account is unified as `ag0` with per-account model discovery and prompt cache countdown.
- **Codex Session Lineage & agm lineage**: Track checkpoint sessions across branches and tasks (`#1943`), with dedicated CLI management.
- **Global API Balance Tracking**: View live Anthropic and OpenAI API balances directly in the header quota strip and dropdown menu across all machines.
- **Smarter Notifications, Translation & Push**: Push notifications for newly released upstream models, retranslation button with partial-untranslated detection, smooth translation swap transitions, and snooze options (1h/1d/3d) for Codex reset credit reminders.
- **Model Standardization & Sorting**: Unified model names and price-ordered sorting (cheapest to most expensive by family) across providers.

## 相容性與升級注意 (Compatibility & Upgrade Notes)

### 1. 建議 CLI 與底層工具版本
v0.2.0 已針對下列最新 upstream 版本進行驗證，建議一併更新以獲得最佳體驗：
- **Claude Code**: `2.1.329`
- **Codex CLI (`@openai/codex`)**: `0.171.0`
- **herdr**: `0.9.5`

### 2. 設定檔結構變更
- **`[openai_api]` 設定區塊**：新增 OpenAI API 支援。可於 `config.toml` 中配置 `key_file`、`enabled`、`balance_anchor_usd` 與 `balance_anchor_at` 等欄位（亦可由網頁「環境設定 → OpenAI API」填入）。
- **`max_turn_cost_microusd` 支援無上限**：`[claude_api.api_bot]` 與 `[openai_api.api_bot]` 中的 `max_turn_cost_microusd` 欄位若留空或省略，代表**不設單回合費用上限**（不再強制要求整數）。
- **`[claude_api.groups.translate]` 供應商設定**：可指定 `provider = "openai"` 將自動翻譯切換為 OpenAI 引擎（需設定 OpenAI API key）。
- **`[agents] fleet_operators`**：支援陣列設定，指定代表主控 daemon 的 Bot 名稱，允許跨專案管理成員生命週期。

### 3. 功能退役與移除
- **移除網頁「最近刪除」頁（Recently deleted）**：環境設定分頁已移除該功能，API `GET /api/bots/deleted` 已退役。
- **執行者池（`executor_pool` / `pool_entry`）退役**：專家模式不再使用預先配置的 executor pool，改由增聘（`agm hire`）時直接指定 kind、model 與 effort。

### 4. 資料庫 Migration 與單向升級
- 本版本包含資料庫 Schema 升級（收納 `openai-api` 等 kind 定義，以及 Codex session 血統表 `lineage_sessions` [SCHEMA 99]）。
- **升級為單向進行**：升級前建議備份 `~/.config/agents-manager/` 資料目錄。以 v0.2.0 啟動後，舊版本二進位檔將無法直接開啟新資料庫；若需回滾至 v0.1.0，請還原升級前的資料庫備份檔案。
